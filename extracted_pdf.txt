Observaciones:
1. Todas las imagenes e iconos a utilizar en este proyecto se encuentra en plataforma BlackBoard.
2. También esta disponible en plataforma BlackBoard un video de cómo funciona la aplicación.
3. Se utiliza el componente serial LazSerial el cual se puede buscar e instalar desde el IDE de
Lazarus (Opción Paquete → Online Package Manager)
4. Los datos se reciben desde un script de python a 9.600 Bps, 8N1 a un sampling de 1 segundo. 
5. El rango de los valores de MP2.5 um se modela con una Distribución Normal(80,5).
6. En  la  interfaz  presentada  el  botón  “Cámara  Fotográfica“  → realiza  una  captura  →
captura.png.

7. El botón “On/Off” → Activa/Desactiva la Grilla del visor.
8. El botón de “Click” → Cambia la figura de fondo (background) del visor.
9. La interfaz debe poseer: Título principal (Top), SubTítulo (Bottom) y con activación en cada
botón de la propiedad Hint.
10. Se debe utilizar el componente TChart el cual incluye la serie de tipo TLinesSeries.
11. Deberá configurar las propiedades de  Legend, LinePen, Marks, Frame, LabelBrush, Style,
Pointer, SeriesColor, etc.
12. La interfaz debe enviar el MP25 recibido a un Server TCP/IP Lazarus Pascal mode consola
que almacene los datos en  SQLITE Tabla Aire  con  Fecha y Hora. Los datos recibidos se
deben mostrar también por consola.
13. Utilice  HeidiSQL_12.3_64_Portable para crear la base de datos y ver la data recibida en
tiempo real.
14. La aplicación que usted desarrollará debe ser similar al demo que está en plataforma.
Observaciones
1. El trabajo Individual o en Grupo de 2 personas.
2. Fecha de defensa del proyecto, semana del 16 al 20 de Noviembre. Coordinar con el ayudante.

estudiantes involucrados en este delito.
